## Features

- Up to 6 players (local / same device)
- Custom round timer (5–120s)
- Random non-repeating letters
- Preset & custom categories
- STOP button (only active when all fields filled)
- Simple user sign-up & profile
- Responsive dark UI with blur effects

## Tech Stack

- HTML5 + CSS3 (vanilla)
- Modern JavaScript (ES6+ modules)
- Font Awesome icons
- No build tools — 100% static

## Quick Start

```bash
git clone https://github.com/EbbsOnline3/My-Bingo-App.git
cd My-Bingo-App
# Just open App.html in browser
# or use live server:
npx serve .
```

## How to Play

1. Sign up (optional)
2. Choose players & names
3. Set timer & categories
4. Click **Start Game**
5. Fill words starting with the letter
6. Complete all fields → click **STOP**
7. Next round or reset

→ Full rules in the **Rules** button
